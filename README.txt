GOODS MANAGER 試作品 v0.1

内容
- イベント / 通常グッズの切り替え
- 商品の追加・編集・削除
- 商品画像の縮小保存と拡大表示
- 定価、任意の実購入価格、数量管理
- 購入価格が未入力なら定価で集計
- 予算と残額の計算
- 検索、商品名 / 価格 / 数量の並び替え
- IndexedDBへの端末内保存
- JSONバックアップの書き出し / 読み込み
- HTTPS公開時の簡易オフラインキャッシュ

注意
これは初期試作品です。まだ実装していない機能：
- 商品URLからの自動情報取得
- イベント会場、来場日、人数、購入制限の計算
- 購入履歴や価格・制限の変更履歴
- 画像キャッシュの一括整理
- iCloud等を使った複数端末同期

iPhoneで使うには
1. このZIPをHTTPS対応の静的ホスティングサービスにアップロードします。
2. 発行されたHTTPSのURLをiPhoneのSafariで開きます。
3. 共有ボタン > ホーム画面に追加 で登録します。
4. 最初の読み込み後、オフライン動作を確認します。

重要：Safariの「ファイル」からindex.htmlを直接開くだけでは、PWAとしてのインストールやService Workerによるオフライン動作はできません。
データはそのブラウザの端末内に保存されます。SafariのWebサイトデータ削除や別ブラウザへの移行で失われる可能性があるため、定期的にバックアップしてください。
