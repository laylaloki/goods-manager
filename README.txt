GOODS MANAGER v0.3.2

今回の修正
- 商品情報の取得件数を、実際に入力欄へ反映できた商品固有情報で判定するよう改善
- 商品名（ページタイトル）だけ取得できた場合は、取得成功と誤表示しない
- JSON-LD Product、商品メタ情報、itemprop情報の読み取りを改善
- Shopify形式の商品ページでは、公開商品JSONの取得も追加で試行
- 手入力済みの項目は上書きしない
- IndexedDBの既存データ形式とJSONバックアップ形式を維持
- Service Workerのキャッシュ名をv0.3.2へ更新

URL自動取得について
ブラウザのCORS制限や各サイトの設定により、取得できないページがあります。全サイトでの自動取得を保証するものではありません。取得できない場合は商品ページを開き、手入力してください。

更新手順
1. 念のため、現在のホーム画面アプリで「データを書き出す」を実行し、JSONバックアップを保存してください。
2. GitHubリポジトリの既存4ファイルを、このフォルダ内の同名4ファイルで置き換えてください。フォルダ自体はアップロードせず、中の4ファイルを選択してください。
3. Commit後、GitHub Pagesの反映を待ち、ホーム画面アプリをオンラインで開き直してください。
4. 商品データが残っていることを確認してください。バックアップJSONは保管してください。

保存データは端末内にあります。Safari版とホーム画面版は保存領域が異なる場合があります。
