GOODS MANAGER v0.3

今回の更新
- 商品ページURLから情報取得を試行（JSON-LD Product情報、Open Graph、基本メタ情報に対応）
- 取得項目：商品名、メーカー、価格、画像URL、JAN/GTIN、発売日（ページ側に情報があり、ブラウザから取得できる場合）
- URLから取得できない場合に商品ページを別タブで開く補助ボタンを追加
- 商品画像URLも商品カードに表示。端末に保存した画像を優先
- 購入店舗・購入日を追加
- v0.2のIndexedDBデータ形式を維持し、既存商品データを引き継ぐ
- JSONバックアップ／読み込みを維持
- Service Workerキャッシュをv0.3に更新

URL自動取得について
ブラウザのセキュリティ制限（CORS）やサイト側の設定により、商品ページを読み込めない場合があります。その場合でもURLは保存でき、商品ページを開いて手入力できます。自動取得の成功を保証するものではありません。

更新時の注意
1. 現在のアプリで「データを書き出す」を実行し、JSONバックアップを保存してください。
2. GitHubのリポジトリに、このフォルダ内の4ファイルをアップロードして既存ファイルを置き換えてください。
3. GitHub Pagesの反映後、ホーム画面アプリを一度オンラインで開いて更新してください。
4. 既存データが表示されることを確認してください。万一に備え、バックアップJSONは保管してください。

保存データは端末内に保存されます。Safari版とホーム画面版は保存領域が異なる場合があります。
