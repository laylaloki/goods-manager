GOODS MANAGER v0.3.3

今回の修正
- Shopify形式の商品ページでは、商品ページHTMLの取得に失敗しても公開商品JSONを独立して試すよう変更
- Shopifyの商品JSONから商品名・メーカー・価格・画像・JAN・公開日を補完
- 既に入力欄に値がある項目は上書きしない
- 取得できた項目数を表示し、取得できない場合は手入力が必要と明示
- Service Workerのキャッシュ名をv0.3.3に更新

重要
- サイト側のCORS設定・アクセス制限はブラウザ側から回避できません。
- そのため、すべての通販サイトで自動取得できる保証はありません。
- 商品データはIndexedDBに保存します。既存データ形式・DB名・ストア名は維持しています。
- 更新前に念のためアプリ内の「データを書き出す」でバックアップを取ってください。
