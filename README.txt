GOODS MANAGER v0.3.5

今回の修正
- 日付欄の表示を「発売日／お届け予定日」に変更
- 商品ページに発売日がなく、お届け予定日が取得された場合も、意味が誤解されにくい表示に変更
- 日付データの保存形式・取得処理は変更していません
- Service Workerのキャッシュ名をv0.3.5に更新

重要
- 既存のreleaseDateデータはそのまま保持されます。削除・初期化しません。
- サイトに明示された発売日・お届け予定日など、ページ側の情報を取得します。ページ側の表記と意味が常に判別できるわけではありません。
- サイト側のCORS設定・アクセス制限により、自動取得できない場合があります。
- 商品情報は取得できた項目だけ入力欄に反映します。取得結果を確認してから保存してください。
- 商品データは既存と同じIndexedDB（goods-manager-db）に保存します。
