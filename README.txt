GOODS MANAGER v0.3.4

今回の修正
- JSON-LDのProduct判定を拡張（schema.orgのURL形式にも対応）
- 商品名・画像・発売日などのitemprop情報の取得を補強
- 発売日欄には明示的なreleaseDate情報だけを採用
- datePublishedやShopify published_at（商品ページ公開日）を発売日として誤登録しないよう変更
- 既に入力欄に値がある項目は上書きしない
- Service Workerのキャッシュ名をv0.3.4に更新

重要
- 対応サイトを増やすため、一般的な構造化データ・商品メタ情報の読み取りを補強しています。
- サイト側のCORS設定・アクセス制限はブラウザ側から回避できません。すべての通販サイトで自動取得できる保証はありません。
- 商品情報は取得できた項目だけ入力欄に反映します。取得結果を確認してから保存してください。
- 商品データはIndexedDBに保存します。既存データ形式・DB名・ストア名は維持しています。
- 今回の更新で既存の商品データを消去する処理はありません。
