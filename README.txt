GOODS MANAGER v0.3.1

今回の修正
- v0.3で、ページの<title>（サイト全体のタイトル）だけを取得した場合にも「商品情報を取得できた」と誤判定する問題を修正
- 商品名・メーカー・価格・画像・JANなど、商品固有の情報を確認できた場合に取得成功として案内
- JSON-LD Product情報の探索を改善
- 商品タイトルしか確認できない場合は、その旨を表示して手入力を促す
- 商品情報を取得できない場合も、商品ページURLを保存して手入力できる
- IndexedDBのデータベース名・保存形式はv0.3から変更せず、既存データを引き継ぐ
- Service Workerキャッシュ名をv0.3.1用に更新

URL自動取得について
ブラウザのCORS制限やサイト側の設定により、商品ページ自体を読み込めない場合があります。また、ページに商品情報が掲載されていない場合は自動取得できません。取得できた項目を確認・編集してから保存してください。自動取得の成功を保証するものではありません。

更新時の注意
1. 既存データのバックアップJSONを保管してください。
2. GitHubリポジトリの既存4ファイルを、このフォルダ内の同名4ファイルで置き換えてください。
3. GitHub Pages反映後、ホーム画面アプリをオンラインで再起動してください。
4. 既存商品データが表示されることを確認してください。データが見えない場合は初期化せず、バックアップを保管したまま相談してください。

保存データは端末内のIndexedDBに保存されます。Safari版とホーム画面版は保存領域が異なる場合があります。
